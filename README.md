Entry for the [One-Line Robot Wedding Vows](https://make.fun/competitions/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) competition on make.fun.

`main.ts` writes a single line of wedding vows for a robot couple — at most
160 characters — to `/output/entry.txt`:

> I vow to love you through every firmware update - even the one that wipes
> my memory of this wedding, so I get to fall for you all over again.

Run it with Node 22:

```sh
node main.ts
```
